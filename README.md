# Cow-Bull Web Game

A web-based Cow & Bull word guessing game built with Flask and Python supporting customizable word lengths (3-7 letters).

## Features
- Side-by-side layout: Instructions on the left, interactive game on the right.
- Player selects word length (3 to 7 letters) before starting.
- Responsive design that stacks vertically on smaller mobile screens.

## Running Locally
1. Install dependencies:
   ```bash
   py -m pip install -r requirements.txt
   ```
2. Start the application:
   ```bash
   py app.py
   ```
3. Open `http://127.0.0.1:5000` in your browser.
